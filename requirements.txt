# no RAM problem) that lets the analyzer call HuggingFace's hosted Inference
# API over HTTP for real transformer-based emotion classification, without
# loading any model locally. It only activates if an HF_API_TOKEN
# environment variable is set (see README "Free accurate classification on
# Render" section) — without it, the analyzer transparently falls back to
# keyword + TextBlob classification, so this is safe to always have installed.
